## Challenges Encountered

1. **Slow software downloads:** The ISO files (Ubuntu and Windows) were large and took a long time to download. I solved this by using a download manager and downloading the files during off-peak hours.
2. **VirtualBox nested virtualization warning:** VirtualBox showed a warning about my CPU virtualization setting being disabled in the BIOS. I solved this by restarting my computer, enabling Intel VT-x/AMD-V in the BIOS settings, and restarting VirtualBox.
3. **GitHub profile customization:** I had trouble making my profile README appear on my GitHub profile because the repository name must exactly match my username. I solved this by creating a repository named after my GitHub username and placing the README.md inside it.

## Reflection

This activity taught me that professionalism in System Administration starts with preparation. Before this laboratory, I knew Git and GitHub only as tools for saving and sharing code. Now I understand that they are much more: Git is the version control system that tracks every change in a configuration or script, and GitHub is where a system administrator shows the world how they work, solve problems, and document their processes. Setting up my workstation also made me realize how many tools a system administrator depends on daily: a code editor for scripting, a virtual machine platform for testing safely, and ISO images for building and experimenting with operating systems without risking the main machine.

Creating my GitHub portfolio repository gave me a new habit: documenting everything. Writing this README in Markdown made me think about how documentation is not just an assignment but a professional deliverable, the same kind of documentation I will write when I document servers, policies, and runbooks in a real organization. Updating my GitHub and LinkedIn profiles also reminded me that employers and internship coordinators look at these platforms as a first impression of my professional identity.

I also learned that problems during setup are normal and solvable. Downloading large ISOs, enabling virtualization, and configuring my profile all took patience and research, exactly the attitude a future system administrator needs when dealing with servers that refuse to cooperate. These tools will support my development by giving me a safe space to practice (VirtualBox), a way to track and share my work (Git/GitHub), and a professional network to learn from (LinkedIn). I am now ready for the rest of the semester.
